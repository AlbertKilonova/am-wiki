## 旧版模板支持的标签

旧版每篇文章都是一个 HTML 模板，正文写在「正文写这下面」之后。模板注释里列出的标签：

- 标题：`h1` ~ `h6`
- 段落与换行：`p`、`br`
- 分隔线：`hr`
- 链接：`a href="..."`
- 列表：`ul` / `ol` + `li`
- 行内样式：`b`、`s`、`ins`、`em`、`mark`
- 进度：`meter`、`progress`
- 代码块：`pre`

## 新站的写法

正文改成 **Markdown** 后，上面这些基本都有对应：

| 旧写法 | 新写法 |
| --- | --- |
| `<h2>` | `## 标题` |
| `<b>` | `**粗体**` |
| `<s>` | `~~删除线~~` |
| `<ul><li>` | `- 列表项` |
| `<pre>` | 三个反引号包起来 |
| `<hr/>` | `---` |

图片旧版建议使用图床；新站同理，正文里直接写 `![说明](https://...)` 即可。
